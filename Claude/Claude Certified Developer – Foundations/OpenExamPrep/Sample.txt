51. A 100,000-token prefix is sent on ten requests to a model priced at $2.00 per million input tokens. The first request writes the prefix to a five-minute cache at 1.25 times base and the other nine read it at 0.1 times base. What is the total prefix cost?
$2.25, adding the write surcharge to ten full-price requests
B $0.25, treating only the initial cache write as billable
C $2.00, the cost of ten full-price uncached requests
> $0.43, one write at $0.25 plus nine reads at $0.02
X Not quite:
Uncached, 100,000 tokens cost 0.1 million times $2.00, or $0.20 per request. The write costs $0.20 times 1.25, or $0.25, and each of the nine reads costs $0.20 times 0.1, or $0.02. Total is $0.25 plus nine times $0.02, which is $0.25 plus $0.18, or $0.43.

121. A long conversation that relies on prompt caching changes the top-level output_config.effort partway through. What is the cost consequence?

123. A tool JSON schema uses free-form strings for fields that are actually enums (status = open/closed). What is the impact?

X Not quite:
The input schema is what the model reasons over when composing arguments. Constraining a field to an enum, with a description of each value, sharply reduces invalid tool calls and the retries they cause. Marking the tool strict makes the API enforce it.

X Not quite:
